# B2B Sport

Marketing website for B2B Sport - Denmark's digital sports equipment platform for clubs.

Part of B2B Sport & Promotion Group ApS.

## Overview

Public-facing promotional website showcasing our revolutionary Club Management System and sports equipment solutions. The site serves as the primary marketing tool to attract clubs to adopt our digital ordering platform.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3002](http://localhost:3002) to view the site in development.

## Production

The production build runs on port 3002:

```bash
npm run build
npm start  # Runs on port 3002
```

Deployed at [https://b2bsport.dk](https://b2bsport.dk)

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS with custom design tokens
- Google Fonts (Baloo 2, Open Sans)
- Multi-language support (Danish, English, German)

## Key Features

- Homepage with hero video, value proposition, sports grid, and brand showcase
- What We Do - Company mission and digital transformation story
- Contact page with multi-office locations and team member profiles
- Full internationalization with locale-based routing
- Azure DevOps CI/CD pipeline deployment
